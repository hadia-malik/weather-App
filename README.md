# 🌤️ Weather App

A simple and responsive **Weather App** built using **HTML, CSS, and JavaScript**. It uses the **OpenWeatherMap API** to fetch and display real-time weather information for different cities.

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Displays current temperature
* ☁️ Displays current weather condition
* 🏙️ Displays the searched city
* 🖼️ Dynamically changes the weather icon based on the weather condition
* 📱 Responsive design
* 🔄 Fetches real-time weather data using an API
* ⚡ Uses JavaScript `fetch()` and `async/await`

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API
* Tailwind CSS

## 🔑 API

This project uses the **OpenWeatherMap API** to retrieve weather information.

You will need your own API key to run the project.

## ⚙️ How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Add your OpenWeatherMap API key to the JavaScript file.
4. Open the project using Live Server or another local development server.
5. Search for any city to view its weather.
